# Medical Daily Checklist v5.2 — first public release

This release includes:
- Offline medication and insulin confirmations.
- AM and PM blood-pressure / pulse history, and blood-glucose history.
- Larger bold confirmation displays.
- Printable clinician reports for 7 days, 14 days, 1 month and 3 months.
- An average row beneath each measurement group, ignoring zero and missing values.
- Local SQLite records, CSV export, and dark mode.

**Requirements:** Windows 10/11 and Python 3.9+ with Tkinter installed. Extract the ZIP and run `INSTALL_WINDOWS.cmd`. The installer sets the app to start at Windows sign-in for the current user.

**Privacy:** Personal records stay on the user's computer; no account or internet connection is required. Local health records are not app-encrypted. Do not publish your real records.

**Not a medical device.** This is a self-recorded log, not medical advice or a substitute for an approved instrument.
